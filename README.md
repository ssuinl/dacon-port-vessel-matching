# 항만 입출항 기록 ↔ 선박 카탈로그 매칭 (Dacon 2026)

데이콘 「항만 문제해결을 위한 AI 기술 공모전」 개인 참가 (2026.10.24 ~ 11.01)

## 목적
항만 입출항 기록 한 행을 보고, 선박 제원 카탈로그(78,595척) 안에서 같은 선박의 `vessel_id`를 찾는 **개체 매칭(entity matching)** 문제입니다.

- 평가: `0.7 × 한글 선박명 행 정확도 + 0.3 × 비한글 행 정확도`
- 제출: 코드 제출 방식(`model/`, `script.py`). L4 GPU, 추론 30분, zip 10GB 제한, 추론 중 인터넷 없음
- 규칙: 학습은 train + catalog만 사용. 공개 사전학습 가중치는 허용. 행 독립 예측(test 분포 사용 금지)

핵심 난점은 **한글로 적힌 외국 선박명**(예: `모닝쿠리어` → `MORNING COURIER`)을 영문 카탈로그와 연결하는 것입니다.

## 데이터
| 파일 | 내용 |
|---|---|
| train.csv | 12,222행: 선박명, 해시된 호출부호, 총톤수·국제총톤수, 국적(한글), 선종(한글), 정답 vessel_id |
| vessel_catalog.csv | 78,595척: 영문 선박명, 선종 약어, 톤수·DWT, 국적(영문) |
| test.csv | 비공개 |

> 대회 데이터는 데이콘 규정상 이 레포에 포함하지 않습니다.

## 방법
### 1. 후보 생성 → 랭킹 2단계 구조
행마다 카탈로그에서 후보 수십 개를 뽑은 뒤, 후보별 피처를 만들고 **LightGBM LGBMRanker(lambdarank)**로 1위를 고릅니다. 한글 행과 비한글 행은 파이프라인을 나눴습니다.

### 2. 한글 선박명 처리
- **자음 골격 키** (`src/phon.py`): 한글은 초성·종성 자음으로, 영문은 발음 규칙으로 바꿔서 같은 공간에서 비교합니다.
- **LLM 합성 데이터:** train의 한글 선박은 382척뿐이라, Qwen2.5-3B/7B로 카탈로그 선박의 한글 표기를 생성해 학습 데이터를 약 5,500척 늘렸습니다.
- **LLM 역음역 (추론 시):** 한글 → 영문 후보를 생성해서 검색과 피처에 씁니다.
  - few-shot 3B → **LoRA 미세조정 3B**(학습쌍 6,548개, 빔 4) → **QLoRA 7B** 결합
  - 학습용 피처는 2-fold OOF로 만들어 누수를 막았습니다.
- 피처: 골격·모음키 유사도, 톤수 오차, 숫자 일치, 국적·선종 호환, LLM 영문 후보와 후보 선박명의 유사도 등 36개

### 3. 비한글 선박명 처리
정규화(접두어 `M/V`·`MT` 제거 등) → 문자열 유사도·톤수 기반 후보 → 랭커. train에 없는 카탈로그 선박으로 오타·약칭 합성 기록을 만들어 학습했습니다.

### 4. 검증과 점수 분해
- 선박 단위 GroupKFold(5)
- 로컬 점수가 포화돼서(0.99+) 리더보드를 잘 예측하지 못했습니다. 그래서 Public 점수를 `0.7·a/532 + 0.3·b/1784`로 분해해 **제출마다 한글·비한글 정답 수를 정확히 역산**했고, 한쪽만 예측하는 탐색 제출로 실험을 진단했습니다.

## 결과
| 버전 | 주요 변경 | Public |
|---|---|---|
| v1 | 베이스라인 + 자음 골격 랭커 | 0.797 |
| v4 | 변형(오타·약칭·톤수결측) 합성 학습 | 0.864 |
| v9 | LLM 생성 한글 선박명 학습 | 0.906 |
| v10 | 추론 시 LLM 역음역 피처 | 0.927 |
| v12 | 해로운 개명 합성 제거 | 0.934 |
| v14 | LoRA 미세조정 역음역 | 0.946 |
| **v15** | **3B LoRA + 7B QLoRA 역음역 결합** | **0.951** |

- 한글 정답 433 → 504 / 532행. 가장 확실하게 효과가 있었던 건 LLM 관련 개선이었습니다: 데이터 생성 +21행, 추론 역음역 +16행, LoRA +8행.
- **확인한 사실:** test 선박은 train과 겹치지 않고(호출부호 조회 0점), train은 "쉬운" 선박(동명 없음, 대형 외국선) 쪽으로 편향돼 있었습니다.
- **실패한 실험:** 개명 합성(비한글 −29행), 2차 LLM 확률 재순위, 톤수 오류 대응, LoRA 과적합 설정. 랭커 시드만 바꿔도 ±5행이 흔들려서 작은 개선은 잡음일 수 있었습니다.
